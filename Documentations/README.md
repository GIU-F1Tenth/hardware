# Documentations

## Overview
This folder contains hardware testing procedures, results, and troubleshooting guides for the F1TENTH platform.

## Folder Structure

- [**LiDARTesting.pdf**](LiDARTesting.pdf): Testing report for LiDAR sensors.
- [**LiPo.Battery.Charger.Testing.Report.pdf**](LiPo.Battery.Charger.Testing.Report.pdf): Battery charger testing documentation.
- [**VESCTesting.pdf**](VESCTesting.pdf): VESC controller testing report.

## Getting Started

1. Review the relevant PDF for your hardware component.
2. Use the documentation for setup, testing, and troubleshooting.
