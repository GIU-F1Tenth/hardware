# Battery Holder

## Overview
This folder contains 3D models and files for battery holders and mounting solutions for the F1TENTH platform.

## Folder Structure

- **Traxxas 4x4 LCG XL battery hold down.3mf**: 3D model for battery hold down.

## Getting Started

1. Use the .3mf file for 3D printing the battery holder.
2. Modify the file as needed for your battery configuration.
