# AntennaMount

## Overview
This folder contains CAD models and gcode files for antenna mounts used in the F1TENTH hardware platform.

## Folder Structure
- **AntennaMount_0.15mm_PLA_MK3S_1h5m.gcode**: G-code file for 3D printing the mount.

## Getting Started

1. Use the .STL file for 3D printing the antenna mount.
2. Refer to the .SLDPRT file for editing or customizing the design.
3. Use the provided gcode for direct printing on compatible printers.

# AntennaMount

## Overview
This folder contains CAD models and gcode files for antenna mounts used in the F1TENTH hardware platform.

## Folder Structure

- [**AntennaMount.SLDPRT**](AntennaMount.SLDPRT): SolidWorks part file for the antenna mount.

- [**AntennaMount_0.15mm_PLA_MK3S_1h5m.gcode**](AntennaMount_0.15mm_PLA_MK3S_1h5m.gcode): G-code file for 3D printing the mount.

## Getting Started

1. Use the .STL file for 3D printing the antenna mount.
2. Refer to the .SLDPRT file for editing or customizing the design.
3. Use the provided gcode for direct printing on compatible printers.
