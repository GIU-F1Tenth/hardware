# Jetson

## Overview
This folder contains CAD models and resources for NVIDIA Jetson modules and accessories used in the F1TENTH platform.

## Folder Structure

- **Jetson_Orin_NX_Orin_Nano_Module_3D_STEP_Model_20230310/**: STEP models for Jetson Orin NX and Nano modules.

## Getting Started

1. Use the STEP models for integration and mounting of Jetson modules.
2. Refer to subfolder documentation for details.
