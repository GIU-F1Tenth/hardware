# Vesc

## Overview
This folder contains models and images for VESC controller mounting and wiring for the F1TENTH platform.

## Folder Structure

- VESC controller part files, images, and wiring diagrams (see folder for details).

## Getting Started

1. Browse the files for VESC controller models and mounting solutions.
2. Use the provided files for integration and wiring reference.
