# BOM

## Overview
This folder contains Bills of Materials for hardware builds, including part numbers, quantities, and suppliers for the F1TENTH platform.

## Folder Structure

- **F1TenthBOM2025.xlsx**: Bill of materials for the 2025 build.
- **Roboracer2026BOM.xlsx**: Bill of materials for the 2026 build.

## Getting Started

1. Open the relevant Excel file for your build year.
2. Use the listed part numbers and suppliers to source components.
