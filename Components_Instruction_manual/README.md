# Components Instruction Manual

## Overview
This folder contains assembly guides, user manuals, datasheets, and technical specifications for sensors, actuators, controllers, and other hardware components of the F1TENTH platform.

## Folder Structure

- Subfolders for Jetson, Lidar, VESC, and other components, each containing relevant manuals and datasheets.

## Getting Started

1. Browse subfolders for the component you need information about.
2. Refer to PDFs and HTML files for assembly, usage, and troubleshooting instructions.
